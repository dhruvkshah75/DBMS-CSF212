# DBMS - CS F212

Database Management Systems CS F212

## Lab Topics

- **Lab1**: `DDL` (Data Definition Language) and `DML` (Data Manupilation Language)
- **Lab2**: `DQL` (Data Query Language), aggregate functions, order by, integrity constraints
- **Lab3**: `ER` diagram to Relational model
- **Lab4**: `Group By`, `Having` and `Set` operations
- **Lab5**: `Joins`(inner join and outer joins) and `Nested Queries`
- **Lab6**: `Joins` and `Cross Product` (cross join)
